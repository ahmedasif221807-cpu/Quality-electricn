# ⚡ Quality Electricn - E-Commerce Website

A modern, fully functional e-commerce website for Quality Electricn built with HTML5, CSS3, and vanilla JavaScript.

## Features

### 🛒 Shopping Experience
- **Product Catalog** - Browse 12+ electrical products with detailed information
- **Filter System** - Filter products by category (Appliances, Electronics, Lighting, Tools)
- **Search Functionality** - Search for products by name or description
- **Shopping Cart** - Add/remove items, view total, and checkout
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices

### 🎨 UI/UX
- Modern gradient design with purple theme
- Smooth animations and transitions
- Interactive product cards with hover effects
- Toast notifications for user actions
- Mobile-friendly navigation

### 📱 Sections
1. **Navigation Bar** - Sticky header with logo, menu, and cart icon
2. **Hero Section** - Eye-catching banner with call-to-action button
3. **Search Bar** - Quick product search feature
4. **Products Section** - Grid display with filtering and product cards
5. **About Us** - Company information and benefits
6. **Contact Section** - Contact form and business information
7. **Shopping Cart Modal** - Full cart management
8. **Footer** - Copyright and credits

## Technologies Used

- **HTML5** - Structure and semantic markup
- **CSS3** - Styling with gradients, animations, and flexbox/grid
- **Vanilla JavaScript** - No dependencies, pure JS for interactivity
- **Responsive Design** - Mobile-first approach with media queries

## How to Use

1. **Browse Products** - Scroll through the products or use filters
2. **Search** - Use the search bar to find specific products
3. **Add to Cart** - Click "Add to Cart" button on any product
4. **View Cart** - Click the cart icon (🛒) in the navbar
5. **Checkout** - Review items and proceed to checkout
6. **Contact** - Use the contact form to send messages

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start shopping!
